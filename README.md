# 🎂 康思义 · 生日快乐

一个送给康思义的小小生日纪念网页，纯 HTML / CSS / JavaScript，打开就能用。

## ✨ 特性

- 粉嫩渐变生日风格
- 飘浮气球 / 爱心 / 星星背景
- 可点击的生日蜡烛 🕯️（CSS 火焰）
- 彩带撒花动画 🎉
- 用 Web Audio 播放《祝你生日快乐》主旋律 🎵
- 响应式设计，手机 / 电脑都能看

## 🚀 在线访问

开启 GitHub Pages 后，访问：

```
https://<你的用户名>.github.io/kang-siyi-birthday/
```

## 🖥️ 本地预览

直接在浏览器打开 `index.html` 即可，或：

```bash
npx serve .
```
